# ASR Experiments

This directory contains Jupyter notebooks used for experimenting with Automatic Speech Recognition models.

Planned experiments include:

* Audio loading and preprocessing.
* Audio signal visualization.
* Feature extraction.
* Pretrained model inference.
* Whisper experimentation.
* wav2vec 2.0 experimentation.
* Model evaluation using WER and CER.

## Planned Notebook Structure

```text
01_audio_exploration.ipynb
02_whisper_inference.ipynb
03_wav2vec_experiment.ipynb
04_model_evaluation.ipynb
```

The notebooks will document experiments and results throughout the ASR development process.
